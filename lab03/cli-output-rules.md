## Rule 1: Never convey status or meaning by colour alone
ANSI colours may highlight status, but every status must also appear as an explicit uppercase word in brackets so screen readers and monochrome terminals convey identical information.
* **Bad:**
  ```text
  E-017  Git Workshop      (rendered in red text with no label)
